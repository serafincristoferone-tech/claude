# Ahorro diario a 10 años

`inversion-diaria.html` grafica cómo crece una inversión de **$200.000 por día** con un rendimiento del **10% efectivo anual** durante **10 años** (capitalización diaria, aporte al cierre de cada día).

| | Monto |
|---|---|
| Total aportado (3.650 aportes) | $730.000.000 |
| Intereses ganados | $490.520.311 |
| **Valor final** | **$1.220.520.311** |

Abrí el archivo en el navegador: el gráfico muestra el valor del portafolio frente al total aportado, con detalle al pasar el cursor y una tabla año por año. Los campos de arriba permiten cambiar el aporte, la tasa y el plazo.
